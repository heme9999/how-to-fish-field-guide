# How to Fish Field Guide

An independent, source-conscious companion site for the 2026 Steam game **How to Fish**. The MVP tests whether useful, fast, indexable game data and a local-first Fishipedia tracker can earn search traffic.

## Included

- Crawlable multi-page HTML instead of a client-only SPA
- Creature database seed page
- Local Fishipedia checklist (no account or tracking)
- Beginner and Spider Crab guides
- XML sitemap, robots.txt, canonical URLs, Open Graph and JSON-LD
- Cloudflare Workers Static Assets deployment

## Local checks

```sh
npm install
npm run check
npx wrangler dev
```

## Data policy

Facts are tagged by verification status. Unverified prices, probabilities and combat formulas are deliberately omitted. This is an unofficial fan project and is not affiliated with Dazed Games.
